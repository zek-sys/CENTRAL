# CENTRAL

Repositório central — [zek-sys/CENTRAL](https://github.com/zek-sys/CENTRAL).

**Central Regatão** — Aplicação de gestão (cockpit) do Instituto Regatão. Refit: React + Vite + Tailwind, Firebase (Auth/Firestore), hubs modulares, Folha de Rosto, Mapa Cultural, financeiro com integração Google Sheets.

## Stack

- React 19, Vite 7, Tailwind CSS 4  
- Firebase (Auth, Firestore)  
- Deploy: Vercel ou Firebase Hosting  

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
